## Generating Diffs

```bash
# single pair (end-to-end: resolve product/version -> fetch (cached) -> extract -> diff)
python cim-diffs.py autodiff "X2D II 100C" 1.1.8.6 "X2D II 100C" 1.3.16.2 --markdown

# bootstrap/incremental sweep: every firmware product, previous vs latest (idempotent)
python cim-diffs.py scan --run

# product catalog & firmware version history (from api.hasselblad.com)
python cim-diffs.py products
python cim-diffs.py versions "X2D II 100C"
```

## Query Diffs

Each pair directory contains the full structured result (`result.json.gz`):

```bash
# example: file-tree change counts for a pair
curl -s https://raw.githubusercontent.com/<user>/<repo>/main/X2D_II_100C/1.1.8.6__vs__1.3.16.2/result.json.gz \
  | gunzip | jq '.tree.counts'
```

Layers per diff: CIM items / OTA images / filesystem tree / ELF symbols / strings /
scripts & configs / lens firmware (per-model, per-role hex regions).
